# AI-ImageGeneration Tools

This directory contains utility tools for the AI-ImageGeneration project. These tools help with testing models, converting images, and generating analytics data for development purposes.

## Tools Overview

### 1. check_models.py
**Model Testing and Comparison**

This tool automatically tests and evaluates different AI image generation models by generating sample images based on prompts defined in `prompts.txt`.

**Key Features:**
- Scans for models in the directory structure defined in `.env` (see `.env.example`)
- Generates test images for each model using prompts from `prompts.txt`
- Automatically detects model type (SD 1.5, SDXL, Flux) and adjusts parameters accordingly
- Supports different model configurations including Flux, Hyper, and Flux-schnell variants
- Configurable number of images per prompt
- **Fixed Seed Management**: Ensures reproducible results by using the same seed for all models with a single prompt, while generating different seeds for multiple image iterations

**Usage:**
```bash
# Set up your .env file first (copy from .env.example)
cp .env.example .env
# Edit .env to configure model directories and output settings
nano .env
# Run the tool
python check_models.py
```

**Configuration (via .env):**
- `MODEL_DIRECTORY`: Path to the directory containing model files
- `MODEL_FILTER`: Optional file containing allowed model names
- `CACHE_DIR`: Directory for HuggingFace cache
- `OUTPUT_DIRECTORY`: Where generated test images will be saved
- `IMAGES`: Number of images to generate per prompt
- `PROMPTS`: Path to the prompts file (default: prompts.txt)
- `FIXED_SEED`: Enable/disable fixed seed mode (default: True). Set to `False` for random seeds
- `SEED_JSON`: Path to save/load seeds from (default: `{OUTPUT_DIRECTORY}/seeds.json`)

**Fixed Seed Management:**

When `FIXED_SEED=True`, the tool ensures that:
- All models generate images with the **same seed for each prompt**
- Multiple image iterations (IMAGES > 1) each get a **unique seed**
- All aspect ratios for a single image use the **same seed**
- Seeds are persisted in a JSON file for reproducibility

**Seed File Structure (seeds.json):**
```json
{
  "prompt_1": {
    "prompt_text": "a beautiful landscape with mountains and a lake",
    "image_1": 1234567890,
    "image_2": 2345678901,
    "image_3": 3456789012
  },
  "prompt_2": {
    "prompt_text": "a futuristic cityscape at night with neon lights",
    "image_1": 4567890123,
    "image_2": 5678901234
  }
}
```

This enables direct comparison of model outputs for the same prompts, allowing you to evaluate differences in quality and style without seed variations affecting the results.

### 2. convert_images.py

A utility for batch converting images to PNG format with optional resizing.

**Key Features:**
- Converts images to PNG format with high quality
- Preserves directory structure when processing folders
- Supports recursive processing of directories
- Optional image resizing while maintaining aspect ratio
- Handles various image formats (JPG, JPEG, PNG, GIF, BMP, WEBP, TIFF)

**Usage:**
```bash
# Basic usage (converts all images in a directory)
python convert_images.py /path/to/images

# Specify output directory
python convert_images.py /path/to/images --output-dir /path/to/output

# Resize images (maximum dimension will be 1024px)
python convert_images.py /path/to/images --max-size 1024
```

### 3. image_evaluation_ui.py
**Interactive Image Evaluation and Rating Tool (Web UI)**

This tool provides a web-based interface to view, compare, and rate images generated by `check_models.py`. It uses Gradio for an intuitive, interactive experience.

**Key Features:**
- Interactive Gradio web interface
- Hierarchical filtering by prompt, image number, and resolution
- Side-by-side comparison of all models for same prompt/image/resolution
- Click-to-select model images for auto-population of model name in rating form
- 1-5 star rating system with persistent storage
- Automatic model name detection from image filenames
- Real-time statistics display with average ratings per model
- Automatic detection of latest output directory
- Loads prompts from `seeds.json` (primary) or `prompts.txt` (fallback)
- Console statistics output on application exit

**Usage:**
```bash
# Run with default settings (uses latest output directory from ./output)
python image_evaluation_ui.py

# Specify custom output directory
python image_evaluation_ui.py --output-dir ./output/20260203_1200

# Run on custom port
python image_evaluation_ui.py --port 7861

# Create public shareable link
python image_evaluation_ui.py --share
```

**Interface Features:**
- **Filter Panel (Left Side)**:
  - Select Prompt: Choose from available prompts
  - View Prompt Text: Display full prompt text
  - Select Image Number: Choose which image iteration to view
  - Select Resolution: Filter by image resolution
  - Load Images: Display all models for selected combination

- **Gallery View (Right Side)**:
  - Compare all models side-by-side with their names and current ratings
  - Click any image to auto-populate its model name in the rating form
  - Image titles show model name and model number (M01, M02, etc.)
  - Star ratings displayed inline with each model's current score

- **Rating System**:
  - Select Model to Rate: Auto-populated when clicking an image
  - Rating Slider: 1-5 star scale
  - Save Rating: Persist ratings to `evaluations.json`
  - Status feedback on save success

- **Statistics**:
  - Show Statistics: View average ratings by model
  - Console output on exit: Final statistics printed when app closes

**Workflow:**
1. Run `check_models.py` to generate test images
2. Run `image_evaluation_ui.py` to open the web interface (accessible at `http://localhost:7860`)
3. Use filter dropdowns to select prompt, image number, and resolution
4. Click "Load Images" to display all model results in the gallery
5. Click any image in the gallery to auto-select its model name
6. Adjust the rating slider (1-5 stars) and click "Save Rating"
7. Click "Show Statistics" to view average ratings per model
8. Press Ctrl+C to exit (statistics will be printed to console)

**Output Files:**
- `evaluations.json`: Stores all ratings with timestamps and metadata
- Console output: Final statistics summary printed on exit

### 4. autoevaluate_images.py
**Automatic Image Quality Evaluation (CLI)**

Evaluates generated images using CLIP similarity, BRISQUE, and a lightweight aesthetics heuristic. Results are saved as structured JSON in the output folder.

**Key Features:**
- Uses `seeds.json` (primary) or `prompts.txt` (fallback) for prompt lookup
- Produces a structured JSON report with overall, per-model, and per-prompt statistics
- Saves results into the evaluated output directory by default

**Usage:**
```bash
# Run against latest output directory
python autoevaluate_images.py

# Specify input directory
python autoevaluate_images.py --input ./output/20260203_1200

# Override output filename (saved inside input directory)
python autoevaluate_images.py --input ./output/20260203_1200 --output evaluation_results.json
```

**Output:**
- `evaluation_results.json` in the selected output folder

## Configuration Files

### seeds.json

Automatically generated by `check_models.py`. Contains all prompts and their associated seeds for reproducible image generation.

**Structure:**
- `prompt_N`: Each prompt with number as key
  - `prompt_text`: The actual prompt string used for generation
  - `image_1`, `image_2`, etc.: Seed values for each image iteration

This file is used by `image_evaluation_ui.py` and `autoevaluate_images.py` as the primary source for prompt text when available.

### prompts.txt

Contains prompts used by the `check_models.py` tool to generate test images. Each line represents one prompt.

**Format:**
- One prompt per line
- Optional format: `N - prompt text` (where N is the prompt number)
- Without numbers, lines are auto-numbered starting from 1

**Note:** `seeds.json` is preferred over `prompts.txt` when both exist, as it contains seed information needed for reproducibility.

### .env.example

Example environment configuration file. Copy this to `.env` and modify the values to configure the tools.

## Typical Workflow

1. **Generate Test Images:**
   ```bash
   python check_models.py
   ```
   This generates images and creates `seeds.json` with prompts and seed values.

2. **Evaluate and Rate Results:**
   ```bash
  python image_evaluation_ui.py
   ```
   Open `http://localhost:7860` in your browser to rate images.

3. **Run Automated Evaluation:**
  ```bash
  python autoevaluate_images.py
  ```
  Results are saved as `evaluation_results.json` in the output folder.

4. **View Results:**
   - Press Ctrl+C in the terminal to exit
   - Final statistics will be displayed in the console
   - Ratings are saved in `evaluations.json` for future reference

## Getting Started

1. Clone the repository
2. Copy `.env.example` to `.env` and configure as needed
3. Install required dependencies (from main project's requirements.txt)
4. Run the desired tool from the `tools/` directory
